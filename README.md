# Three Times a Day

Kotlin Multiplatform приложение для локального планирования приёма лекарств на Android и iOS.

## Возможности

- препараты, дозировки, даты курса и отметки о приёмах хранятся только на устройстве;
- ежедневные напоминания в точное время или относительно режима дня;
- календарное правило «каждые N месяцев, в день D» — например, каждые 3 месяца 14-го числа;
- отметки «принято», «пропущено» и отложенный на 10 минут приём;
- Android пересоздаёт ближайшее напоминание после перезагрузки, смены времени и срабатывания предыдущего уведомления;
- на Android 12+ приложение может открыть системный экран для разрешения точных будильников.

Приложение не является медицинским изделием и не заменяет назначений врача.

## Локальная разработка

Требуется JDK 21.

```bash
./gradlew :shared:allTests :androidApp:assembleDebug
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64
```
